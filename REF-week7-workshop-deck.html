What is
TypeScript?

JavaScript, with the types written down.

That's the whole answer. It is not a new language — it is the JavaScript you already write, plus notes about what each thing is allowed to be. Delete the notes and you have JavaScript back. The notes are for a checker that reads your code before it runs.

.mts = m odule + t ype s cript

Same code, twice · only the highlighted parts are new

The types written down

JAVASCRIPT — you already write this: let team = "TCS-ServiceDesk-L1-NA-WE"; let open = 52; function isBusy(count) { return count > 40; } TYPESCRIPT — the identical code, plus the notes: let team: string = "TCS-ServiceDesk-L1-NA-WE"; let open: number = 52; function isBusy(count: number): boolean { return count > 40; } Now this mistake is caught BEFORE the server starts: isBusy("fifty-two"); ^ Argument of type 'string' is not assignable to parameter of type 'number'.

I say: "Four small notes. That's the entire difference on this slide. And the payoff is the last line — a bug the client never sees, because the code wouldn't even start."

The shapes your
API trades in

From code/path-typescript-api.mts — the real file: type Row = Record<string, string>; type TeamCount = { team: string; open: number }; type Alert = { team: string; open: number; rule: string; at: string }; And then every route PROMISES to return one of those shapes: function qOpenByTeam(): TeamCount[] { ... } function qTickets(team: string) { ... }
